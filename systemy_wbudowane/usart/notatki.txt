Krok 2: Ustawienie trybu nadawania
W ATmega32 rejestr kontrolny USART, UCSRB, pozwala na włączenie nadajnika. Aby to zrobić:

Ustawiamy bit TXEN w rejestrze UCSRB na 1, aby włączyć tryb nadawania.
Ustawiamy bity URSEL w rejestrze UCSRC (wybiera rejestr UCSRC) oraz UCSZ0 i UCSZ1 na 1 (konfiguracja 8-bitowego trybu danych).
Przykładowy kod konfiguracji USART
c
Skopiuj kod
#include <avr/io.h>

void USART_Init(void) {
    // Ustawienie wartości UBRR na 25 dla prędkości 9600 bps
    unsigned int ubrr = 25;
    UBRRH = (unsigned char)(ubrr >> 8);  // Wysoki bajt UBRR
    UBRRL = (unsigned char)ubrr;         // Niski bajt UBRR

    // Włączenie nadawania (TXEN) i odbierania (RXEN)
    UCSRB = (1 << TXEN) | (1 << RXEN);

    // Ustawienie trybu 8-bitowego, 1 stop bit, no parity
    UCSRC = (1 << URSEL) | (1 << UCSZ1) | (1 << UCSZ0);
}
Ten kod konfiguruje port USART do nadawania z prędkością 9600 bps w trybie 8N1 (8 bitów danych, brak parzystości, 1 bit stopu).

Pytanie 2: Jak określić moment wysłania kolejnej danej poprzez port USART?
Aby określić, czy możemy wysłać kolejną daną, musimy sprawdzić, czy bufor nadawczy USART jest pusty. W ATmega32 jest do tego specjalny bit UDRE (USART Data Register Empty), który znajduje się w rejestrze stanu UCSRA.

Jeśli UDRE jest ustawiony na 1, oznacza to, że bufor nadawczy jest pusty i możemy zapisać kolejną daną do rejestru danych UDR.
W przeciwnym razie, musimy poczekać, aż bufor nadawczy się opróżni.
Przykład kodu do wysyłania danych przez USART
c
Skopiuj kod
void USART_Transmit(unsigned char data) {
    // Czekaj, aż bufor nadawczy będzie pusty (UDRE = 1)
    while (!(UCSRA & (1 << UDRE)));

    // Wyślij daną, zapisując ją do rejestru UDR
    UDR = data;
}
W powyższym kodzie funkcja USART_Transmit sprawdza, czy bit UDRE jest ustawiony, zanim zapisze kolejną daną do rejestru UDR.

UCSRA – Rejestr stanu (USART Control and Status Register A)

UCSRA zawiera bity kontrolne i statusowe używane do monitorowania statusu USART.
Główne bity w UCSRA to:
RXC – Flaga zakończenia odbioru (Receive Complete): ustawiona na 1, gdy odbiór danych przez USART jest zakończony.
TXC – Flaga zakończenia transmisji (Transmit Complete): ustawiona na 1, gdy transmisja danych jest zakończona.
UDRE – Flaga opróżnienia rejestru danych (USART Data Register Empty): ustawiona na 1, gdy rejestr UDR jest gotowy na przyjęcie nowych danych do wysłania.
FE – Błąd ramki (Frame Error): ustawiona na 1, gdy wykryty zostanie błąd ramki (np. nieprawidłowy bit stopu).
DOR – Błąd przepełnienia danych (Data OverRun): ustawiona na 1, gdy nowe dane nadpisały nieodebrane dane w buforze odbiorczym.
PE – Błąd parzystości (Parity Error): ustawiona na 1, gdy wystąpi błąd parzystości.
U2X – Podwójna prędkość transmisji (Double the USART Transmission Speed): ustawienie tego bitu pozwala podwoić szybkość transmisji w trybie asynchronicznym, obniżając wartość dzielnika.
UCSRB – Rejestr kontroli B (USART Control and Status Register B)

UCSRB służy do włączania lub wyłączania nadawania i odbierania oraz do konfiguracji długości danych i przerwań USART.
Główne bity w UCSRB to:
RXCIE – Przerwanie odbioru zakończone (RX Complete Interrupt Enable): pozwala włączyć przerwanie po zakończeniu odbioru danych.
TXCIE – Przerwanie zakończenia transmisji (TX Complete Interrupt Enable): pozwala włączyć przerwanie po zakończeniu transmisji danych.
UDRIE – Przerwanie opróżnienia rejestru danych (USART Data Register Empty Interrupt Enable): pozwala włączyć przerwanie, gdy rejestr UDR jest pusty i gotowy do przyjęcia nowych danych do wysłania.
RXEN – Włączenie odbiornika (Receiver Enable): ustawienie tego bitu na 1 włącza odbiornik USART.
TXEN – Włączenie nadajnika (Transmitter Enable): ustawienie tego bitu na 1 włącza nadajnik USART.
UCSZ2 – Bit konfiguracji długości danych (Character Size Bit 2): używany razem z bitami UCSZ1 i UCSZ0 w rejestrze UCSRC, aby ustawić liczbę bitów danych (5-9 bitów).
RXB8 i TXB8 – Dodatkowy bit dla trybu 9-bitowego: służą jako dziewiąty bit danych w przypadku ustawienia transmisji na 9-bitową.
UCSRC – Rejestr kontroli C (USART Control and Status Register C)

UCSRC jest używany do konfiguracji formatu ramek danych (długość słowa, liczba bitów stopu, parzystość).
Główne bity w UCSRC to:
URSEL – Wybór rejestru (Register Select): ustawiony na 1 wybiera rejestr UCSRC, a ustawiony na 0 wybiera rejestr UBRRH.
UMSEL – Wybór trybu (Mode Select): ustawia tryb pracy USART. 0 wybiera tryb asynchroniczny, a 1 – synchroniczny.
UPM1 i UPM0 – Tryb parzystości (Parity Mode): służą do konfiguracji parzystości (bez parzystości, parzystość parzysta, parzystość nieparzysta).
USBS – Liczba bitów stopu (Stop Bit Select): 0 – jeden bit stopu, 1 – dwa bity stopu.
UCSZ1 i UCSZ0 – Konfiguracja długości danych (Character Size): używane razem z bitem UCSZ2 z UCSRB do ustalenia liczby bitów danych (5, 6, 7, 8 lub 9 bitów).
UCPOL – Polaryzacja zegara w trybie synchronicznym (Clock Polarity): 0 – wyzwalanie zboczem opadającym, 1 – zboczem narastającym (dla transmisji synchronicznej).
UDR – Rejestr danych USART (USART Data Register)

UDR jest 8-bitowym rejestrem, przez który przesyłane są dane. Do rejestru UDR zapisuje się dane do wysłania, a podczas odbierania dane są automatycznie ładowane do UDR.
Nadanie danych do UDR rozpoczyna transmisję USART.
Przy odbiorze dane są umieszczane w UDR, gdy USART zakończy odbiór bajtu.

volatile uint8_t last_error = 0; // Zmienna do przechowywania ostatniego błędu USART

// Inicjalizacja USART
void USART_Init(void) {
    // Ustawienie wartości UBRR
    uint16_t ubrr = MYUBRR;
    UBRRH = (uint8_t)(ubrr >> 8);  // Wyższy bajt UBRR
    UBRRL = (uint8_t)ubrr;         // Niższy bajt UBRR

    // Włączenie nadajnika, odbiornika oraz przerwań odbioru i opróżnienia rejestru danych
    UCSRB = (1 << RXEN) | (1 << TXEN) | (1 << RXCIE) | (1 << UDRIE);

    // Konfiguracja formatu ramki: 8 bitów danych, brak parzystości, 1 bit stopu
    UCSRC = (1 << URSEL) | (1 << UCSZ1) | (1 << UCSZ0);

    // Zerowanie flagi błędów
    last_error = 0;
}

// Funkcja do nadawania pojedynczego bajtu
void USART_TransmitByte(uint8_t data) {
    while (!(UCSRA & (1 << UDRE)));  // Czekanie na opróżnienie rejestru
    UDR = data;                      // Wysłanie bajtu danych
}

// Funkcja do odbierania pojedynczego bajtu
uint8_t USART_ReceiveByte(void) {
    while (!(UCSRA & (1 << RXC)));  // Czekanie na zakończenie odbioru
    if (UCSRA & ((1 << FE) | (1 << DOR) | (1 << PE))) {
        last_error = UCSRA & ((1 << FE) | (1 << DOR) | (1 << PE));  // Zapis błędu
        return 0;  // Zwróć 0 przy błędzie
    }
    return UDR;  // Zwróć odebrany bajt
}

// Funkcja do wysyłania ciągu znaków (string)
void USART_TransmitString(const char* str) {
    while (*str) {
        USART_TransmitByte(*str);
        str++;
    }
}

// Funkcja do odbierania ciągu znaków (z określeniem maksymalnej długości)
void USART_ReceiveString(char* buffer, uint8_t maxLen) {
    uint8_t i = 0;
    for (i = 0; i < maxLen - 1; i++) {
        char received = USART_ReceiveByte();
        if (received == '\n' || received == '\r') break;  // Zakończenie stringu przy znaku nowej linii
        buffer[i] = received;

Jeśli jednak potrzebujesz podłączenia ATmega32 do urządzenia zewnętrznego w trybie synchronicznym USART (gdzie zegar jest współdzielony między urządzeniami), musimy uwzględnić również dodatkową linię zegara, jak poniżej.

Podłączenie ATmega32 do urządzenia zewnętrznego w trybie USART synchronicznym
Wymagane połączenia:

MISO/MOSI: Jeden mikrokontroler wysyła dane jako master (gospodarz), drugi odbiera jako slave (podrzędny). W przypadku ATmega32 pełni on zwykle rolę mastera.
SCK: Linia zegara (Synchronous Clock).
GND: Masa wspólna.
Schemat połączeń w trybie synchronicznym USART:

lua
Skopiuj kod
                 ATmega32               Urządzenie zewnętrzne (Slave)
              +------------+               +-----------------+
              |            |               |                 |
    TX (PD1)  --------->   RX              |                 |
    RX (PD0)  <---------   TX              |                 |
    XCK (PD4) --------->   SCK             |                 |
    GND       --------->   GND             |                 |
              |            |               |                 |
              +------------+               +-----------------+
Opis sygnałów:
TX (PD1) i RX (PD0): Linia danych, podobnie jak w trybie UART.
XCK (PD4): Linia zegara, którą w trybie synchronicznym USART ATmega32 generuje na swoim wyjściu XCK.
GND: Masa wspólna.
Konfiguracja rejestrów dla USART w trybie synchronicznym:
Aby skonfigurować ATmega32 w trybie synchronicznym USART, trzeba:

Ustawić bit UMSEL (w rejestrze UCSRC) na 1, co przełącza mikrokontroler w tryb synchroniczny.
Wybrać tryb master/slave, ustawiając odpowiednio bit UCSZ oraz bity kontrolujące zegar (np. UCPOL dla fazy zegara).
W trybie synchronicznym USART ATmega32 wymaga skonfigurowania linii zegara XCK oraz dokładnego zsynchronizowania prędkości zegara, co zapewnia lepszą synchronizację danych niż tryb UART.

Jak działa ISR w ATmega32?
Przerwanie: W systemie mikrokontrolera ATmega32, każde przerwanie jest zdarzeniem, które może być wywołane przez różne podsystemy lub peryferia, np. UART, TIMER, SPI, ADC.
Zarejestrowanie procedury: Programista rejestruje procedurę ISR jako obsługę dla konkretnego przerwania. W kodzie, ISR jest oznaczana poprzez makro ISR(vector_name), gdzie vector_name to nazwa konkretnego przerwania.
Automatyczne wywołanie: Gdy określone zdarzenie wystąpi, mikrokontroler automatycznie przerywa wykonywanie głównego programu i przechodzi do wykonania kodu ISR przypisanego do tego przerwania.
Zakończenie ISR: Po wykonaniu kodu ISR mikrokontroler automatycznie wraca do głównego programu, kontynuując działanie od miejsca, w którym nastąpiło przerwanie.
Przykład użycia ISR w ATmega32
Poniżej przedstawiono prosty przykład ISR dla przerwania odbioru danych przez USART (przerwanie USART_RXC_vect):

c
Skopiuj kod
#include <avr/io.h>
#include <avr/interrupt.h>

volatile uint8_t receivedData = 0;

// Inicjalizacja USART
void USART_Init(void) {
    uint16_t ubrr = 25; // Dla 9600 bps przy F_CPU = 4 MHz
    UBRRH = (uint8_t)(ubrr >> 8);
    UBRRL = (uint8_t)ubrr;

    UCSRB = (1 << RXEN) | (1 << TXEN) | (1 << RXCIE);  // Włączenie RX, TX i przerwań RX
    UCSRC = (1 << URSEL) | (1 << UCSZ0) | (1 << UCSZ1); // 8 bitów danych, 1 bit stopu
}

// ISR dla odbioru danych przez USART
ISR(USART_RXC_vect) {
    receivedData = UDR; // Odczyt danych z rejestru UDR, który przechowuje odebrane dane
}

int main(void) {
    USART_Init(); // Inicjalizacja USART
    sei(); // Włączenie globalnych przerwań

    while (1) {
        // Główny program – tutaj można używać zmiennej receivedData po odebraniu danych
    }
}

Funkcja USART_Init() konfiguruje interfejs USART i włącza przerwanie odbioru danych przez ustawienie bitu RXCIE w rejestrze UCSRB.
ISR dla przerwania USART_RXC_vect:

ISR dla USART_RXC_vect wykonuje się, gdy mikrokontroler odbierze dane przez USART.
W procedurze ISR następuje odczyt odebranych danych z rejestru UDR i zapisanie ich do zmiennej receivedData.
Dzięki temu dane są przechwytywane natychmiast po odebraniu, bez konieczności ciągłego sprawdzania przez główny program, czy nowe dane są dostępne.
Globalne przerwania (sei()):

sei() włącza globalne przerwania, umożliwiając wywoływanie wszystkich zarejestrowanych ISR.
Cechy i ograniczenia ISR:
Brak opóźnień: ISR powinny być możliwie krótkie, aby nie blokować innych przerwań i nie powodować opóźnień w głównym programie.

Globalne przerwania: ISR działają tylko wtedy, gdy globalne przerwania są włączone (sei()).
Zmienne typu volatile: Zmienna używana przez ISR powinna być oznaczona jako volatile, aby kompilator wiedział, że jej wartość może ulec zmianie poza głównym programem.

Dzięki ISR mikrokontroler może efektywnie reagować na zewnętrzne sygnały i zdarzenia, bez angażowania głównego programu w ciągłe sprawdzanie stanów peryferiów.

USART i przerwania w ATmega32
W ATmega32 interfejs USART pozwala na obsługę przerwań, które przyspieszają i upraszczają wymianę danych. Mikrokontroler oferuje kilka przerwań USART:

USART_RXC_vect: Przerwanie generowane przy odbiorze pełnego bajtu danych.
USART_TXC_vect: Przerwanie generowane po zakończeniu wysyłania pełnego bajtu danych.
USART_UDRE_vect: Przerwanie generowane, gdy bufor danych wysyłania (rejestr UDR) jest pusty i gotowy do przyjęcia nowego bajtu danych.
W przypadku przerwań USART_RXC_vect i USART_TXC_vect przerwanie jest wywoływane, gdy odbierany lub wysyłany bajt jest kompletny. Natomiast USART_UDRE_vect pozwala programowi na załadowanie kolejnego bajtu do bufora nadawczego, zanim bieżący bajt zakończy wysyłanie.

Przerwanie USART_UDRE_vect — do czego służy?
Przerwanie USART_UDRE_vect jest wywoływane, gdy rejestr danych USART (UDR) jest pusty, co oznacza, że USART jest gotowy do przyjęcia nowego bajtu do wysłania. Używa się go do:

Utrzymania ciągłości transmisji: Załadowanie kolejnych bajtów do UDR bez opóźnień między nimi.
Efektywnej transmisji danych: Gdy tylko poprzedni bajt zaczyna się transmitować, nowe dane mogą być ładowane do UDR, co zwiększa przepustowość transmisji.

#include <avr/io.h>
#include <avr/interrupt.h>

#define BAUD 9600
#define MYUBRR F_CPU/16/BAUD-1

volatile uint8_t received_byte = 0; // Przechowywanie odebranego bajtu
volatile uint8_t transmit_data = 0; // Przechowywanie bajtu do wysłania
volatile uint8_t data_ready = 0;    // Flaga, czy nowy bajt jest gotowy do wysłania

// Inicjalizacja USART
void USART_Init(uint16_t ubrr) {
    UBRRH = (uint8_t)(ubrr >> 8);
    UBRRL = (uint8_t)ubrr;
    UCSRB = (1 << RXEN) | (1 << TXEN) | (1 << RXCIE) | (1 << UDRIE); // Włącz odbiór, nadawanie, przerwanie RX i UDRIE
    UCSRC = (1 << URSEL) | (1 << UCSZ0) | (1 << UCSZ1); // 8 bitów danych, 1 bit stopu
}

// Funkcja ustawiająca bajt do wysłania
void USART_Transmit_Byte(uint8_t data) {
    transmit_data = data;
    data_ready = 1; // Ustaw flagę gotowości danych do wysłania
}

// ISR dla przerwania odbioru danych
ISR(USART_RXC_vect) {
    received_byte = UDR; // Odczyt bajtu z UDR po odebraniu
}

// ISR dla przerwania pustego bufora nadawczego (gotowość do transmisji)
ISR(USART_UDRE_vect) {
    if (data_ready) {
        UDR = transmit_data; // Przepisz bajt do UDR, aby rozpocząć wysyłanie
        data_ready = 0;      // Zresetuj flagę, ponieważ bajt został załadowany do transmisji
    }
}

int main(void) {
    USART_Init(MYUBRR); // Inicjalizacja USART z określoną wartością baud
    sei();              // Włączenie globalnych przerwań

    while (1) {
        // Główna pętla może np. ustawić bajt do wysłania, korzystając z USART_Transmit_Byte().
        // Po odebraniu danych można korzystać z received_byte.
    }
}

Odbiór danych:

ISR USART_RXC_vect jest wywoływane, gdy mikrokontroler odbierze bajt danych.
Odbierany bajt jest odczytywany z rejestru UDR i zapisywany do received_byte.
Wysłanie danych:

Funkcja USART_Transmit_Byte ustawia bajt do wysłania w zmiennej transmit_data i ustawia flagę data_ready na 1.
ISR USART_UDRE_vect sprawdza flagę data_ready. Jeśli flaga jest ustawiona, ISR ładuje bajt z transmit_data do rejestru UDR i resetuje flagę data_ready, co pozwala uniknąć ponownego ładowania tego samego bajtu.
Globalne przerwania:

sei() włącza globalne przerwania, umożliwiając wywołanie zarejestrowanych ISR dla USART.
Podsumowanie

USART_UDRE_vect: Wywoływane, gdy bufor nadawczy jest pusty, co pozwala na ładowanie kolejnych bajtów do transmisji, bez konieczności czekania na zakończenie wysyłania poprzedniego bajtu.

c
Skopiuj kod
#include "usart.h"

#define BAUD 9600
#define MYUBRR F_CPU/16/BAUD-1

volatile uint8_t transmit_data = 0; // Przechowywany bajt do wysłania
volatile uint8_t data_ready = 0;    // Flaga gotowości bajtu do wysłania
volatile const char *transmit_string = NULL; // Wskaźnik na łańcuch znaków do wysłania

// Inicjalizacja USART
void USART_Init(uint16_t ubrr) {
    UBRRH = (uint8_t)(ubrr >> 8);
    UBRRL = (uint8_t)ubrr;
    UCSRB = (1 << RXEN) | (1 << TXEN) | (1 << UDRIE); // Włączenie odbiornika, nadajnika i przerwania UDRIE
    UCSRC = (1 << URSEL) | (1 << UCSZ0) | (1 << UCSZ1); // 8 bitów danych, 1 bit stopu
}

// Funkcja wysyłająca pojedynczy bajt przez USART
void USART_Transmit_Byte(uint8_t data) {
    while (!(UCSRA & (1 << UDRE))); // Czekaj, aż bufor nadawczy będzie pusty
    UDR = data;                     // Załaduj bajt do rejestru UDR
}

// Funkcja wysyłająca ciąg znaków
void USART_Transmit_String(const char* str) {
    transmit_string = str; // Ustaw wskaźnik na łańcuch znaków do wysłania
    USART_Transmit_Byte(*transmit_string++); // Rozpocznij wysyłanie od pierwszego znaku
}

// ISR dla przerwania pustego bufora nadawczego (USART_UDRE_vect)
ISR(USART_UDRE_vect) {
    if (transmit_string && *transmit_string) { // Jeśli znak do wysłania
        UDR = *transmit_string++; // Przepisz następny znak do UDR
    } else {
        UCSRB &= ~(1 << UDRIE); // Wyłącz przerwanie UDRIE, gdy łańcuch został wysłany
        transmit_string = NULL; // Zresetuj wskaźnik na łańcuch
    }
}

// Inicjalizacja Timer 0 do generowania przerwania co pewien czas (dla migania LED_0)
void Timer0_Init(void) {
    TCCR0 = (1 << WGM01) | (1 << CS02);  // Tryb CTC, preskaler 256
    OCR0 = 77;                           // Ustawienie wartości porównania (dla 1 Hz, F_CPU = 4 MHz)
    TIMSK |= (1 << OCIE0);                // Włączenie przerwania od porównania
}

// ISR dla przerwania Timer 0 (do migania LED_0)
ISR(TIMER0_COMP_vect) {
    PORTA ^= (1 << PA0);  // Zmieniamy stan diody LED_0
}

int main(void) {
    // Inicjalizacja portów A
    DDRA = 0xFF;  // Ustawienie wszystkich pinów PA0-PA7 jako wyjścia
    PORTA = 0x00;  // Ustawienie początkowego stanu diod na wyłączony
