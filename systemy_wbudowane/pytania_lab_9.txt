1. Pytanie 1. Jak adresujemy i kodujemy pozycję piksela i jego kolor na wyświetlacz
LCD?
Aby adresować pojedynczy piksel, należy określić jego położenie wzg. piksela piksela
początkowego. Na przykład, aby określić pojedynczy piksel w (2, 7), użyj następującej
sekwencji.
 WriteSpiCommand(PASET); // Row address set (command 0x2B)
 WriteSpiData(2); // startingx address
 WriteSpiData(2); // ending x address (same as start)
 WriteSpiCommand(CASET); // Column address set (command 0x2A)
 WriteSpiData(7); // starting y address
 WriteSpiData(7); // ending y address (same as start)
Aby zająć się prostokątnym obszarem pikseli, po prostu określ lokalizację początkową i
końcową na każdej osi, jak pokazano poniżej. Na przykład, aby zdefiniować prostokąt
rysunku od (4, 3) do (11, 9), użyj następującej sekwencji.
 WriteSpiCommand(PASET); // Row address set (command 0x2B)
 WriteSpiData(4); // startingx address
 WriteSpiData(11); // endingx address
 WriteSpiCommand(CASET); // Column address set (command 0x2A)
 WriteSpiData(3); // starting y address
 WriteSpiData(9); // ending y address
